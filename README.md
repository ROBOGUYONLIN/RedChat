# RedChat
RedChat is a Chatting Client for ComputerCraft: Tweaked.

RedChat is designed to be simple to use, simple to setup and overall, convenient.

Note: AI was NOT used in the making of all the files here.

To download, paste the following command (http must be enabled)
```
wget https://raw.githubusercontent.com/ROBOGUYONLIN/RedChat/refs/heads/main/setup-account.lua setup-account.lua
```
then run 
```
setup-account
```
